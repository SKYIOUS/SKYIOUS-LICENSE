# SKYIOUS LICENSE Governance

## Stewardship
- **Current Steward**: SKYIOUS GitHub account holder
- **Contact**: Via GitHub Issues at https://github.com/SKYIOUS/SKYIOUS-LICENSE/issues
- **Succession**: If account becomes inactive for 12+ months, stewardship transfers to:
  - Primary: GitHub Staff via support process
  - Secondary: Community vote via GitHub Discussions

## Contribution Guidelines
- License modifications require:
  - 30-day public comment period
  - Consensus from 3+ active contributors
